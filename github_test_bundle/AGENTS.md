# 测试包协作约定

- 默认工作是运行行为测试、保存并检查轨迹。正式语义审核和成绩确认由项目负责人统一执行。
- 使用 `redact_bench.py` 作为统一入口，具体动作遵循当前题目观察中的工具协议。
- 被测模型输入只允许已揭示观察、已揭示图片和本轮历史。不得把隐藏世界、rubric、参考轨迹或 A/B 差异说明加入 prompt。
- 密钥只从隐藏提示或已有环境变量读取，不写入代码、文档、配置、轨迹或 Git。
- 每次测试使用新输出目录，不改数据、不重写旧轨迹、不把参考回放当作模型成绩。
- 提交前执行 `check-run` 和 `export`，只把导出的轨迹 ZIP 交给负责人。没有明确指令时不要启动全部400题。
- `verify` 和集成测试均为离线环境检查，不产生模型 API 费用。
